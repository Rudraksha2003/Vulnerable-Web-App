FLAG{A02_Default_Creds_Left_On_Server}

What happened?

This page simulated a sample application left in production with default credentials still enabled (admin / admin). An attacker who knows or guesses default passwords can take over the console.

Remediation: Remove sample or demo applications from production. If you must keep them, change all default passwords and restrict access (e.g. by IP or VPN).
